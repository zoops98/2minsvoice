# 2분 강의

`index.html`을 더블 클릭해 실행합니다. 인터넷 연결과 Gemini API 키가 필요합니다. API 키는 현재 브라우저의 로컬 저장소에 저장되며 암호화되지 않습니다. 같은 컴퓨터나 브라우저를 다른 사람이 사용하는 경우 주의하세요.

강의 설정에서 필기형 강의, 종합 해설형 강의, 대화형 팟캐스트를 선택합니다. 필기형은 10·15분에서도 업로드한 필기 순서대로 문장과 표시를 짚습니다. 종합 해설형은 글 전체의 주제와 전개를 설명하고, 10·15분에는 주제 → 핵심 문장과 구문 → 어휘와 해석 → 요약 순서로 진행합니다.

2·3·5·10·15분은 목표 시간이며 실제 길이는 대본과 말하기 속도에 따라 달라집니다. 긴 음성은 여러 번 생성하여 하나로 합치므로 시간이 걸리고 API 사용량이 늘어납니다. 자막은 완성된 음성을 Gemini 음성 인식에 보내 받은 단어 시간을 기준으로 생성합니다. 고유명사와 영어 철자는 편집할 때 확인하세요.

개발 시 `npm install`, `npm run dev` 후 표시되는 주소의 `/source.html`을 엽니다. `npm run lint`로 코드를 검사하고 `npm run build`로 최종 단일 `index.html`을 다시 만듭니다. `src`는 수정용 원본이고 `source.html`과 `build-single.mjs`는 단일 파일을 만드는 데 사용됩니다.
